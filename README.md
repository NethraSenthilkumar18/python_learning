# Escape Room 

A beginner-friendly Python mini-game where the player is trapped inside a mysterious room and must solve challenges to escape.

How It Works

- A random 3-digit secret code is generated.
- The player gets 3 attempts to guess the code.
- A correct guess unlocks the first room.
- If all attempts are used, the game ends.
- Successfully solving Room 1 leads to Room 2.

Concepts Used

- random module
- input()
- int()
- if-else
- for loop
- break
- for-else loop
